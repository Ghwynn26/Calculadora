# Calculadora
Aprendiendo a crear webs con una app de una calculadora.

## Descripción
Estoy aprendiendo programación de manera autodidacta con el uso de material audiovisual como cursos y videos, incorporando herramientas de desarrollo y buenas prácticas.

Este es el primer proyecto de los que fui desarrollando poco a poco.

Se trata de una calculadora básica que permite realizar las operaciones matemáticas más simples (suma, resta, multiplicación y división).
